# Security policy

Copy to the repository root (or `.github/SECURITY.md`) during bootstrap and fill the brackets.

## Reporting a vulnerability

Do not open a public issue. Report privately to **[security contact or GitHub private advisory link]** with:
the affected version or commit, steps to reproduce, impact, and any proof of concept.
We acknowledge within **[N] business days** and agree on a fix and disclosure date with you.

## Supported versions

| Version | Supported |
|---|---|
| [latest release / main] | yes |

## Scope

In scope: this repository's code and its default configuration. Out of scope: third-party
services, social engineering, denial of service by volume. Never test against real users' data.

# Code of conduct / ميثاق التعامل

Be respectful and helpful. No harassment, insults or discrimination, in any language. Discuss the
work, not the person. Medical content is discussed to learn, with care for patients' privacy:
never share a patient's identifying details.

كن محترماً ومعيناً. لا إساءة ولا إهانة ولا تمييز بأي لغة. ناقش العمل لا الشخص. ولا تشارك أي تفاصيل
تعرّف بمريض.

Problems: report them privately to the maintainer through the repository's Security tab.

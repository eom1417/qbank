# سجل القرارات

قرارات المالك المفتوحة في وثيقة المنتج (القسم 29)، والقرارات الإضافية التي ظهرت أثناء التخطيط. يتحقق منه `tests/unit/docs/traceability.test.ts`.

**القواعد:**

- لا تبدأ أي خطوة تحتاج قراراً قبل أن يُطرح القرار على المالك.
- إن لم يُحسم القرار، يُطبَّق «اقتراح الوثيقة» مؤقتاً، وتصبح الحالة `assumed`.
- عند الحسم تصبح الحالة `decided`، ويُسجَّل القرار ومن اتخذه وتاريخه.
- المرحلة M18 لا تُغلق وفيه قرار غير محسوم (`decided`).

**الحالات:** `open` لم يُطرح بعد · `assumed` يُطبَّق الاقتراح مؤقتاً · `decided` حسمه المالك.

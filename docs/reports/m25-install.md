# M25: تثبيت ينجح من أول مرة

التاريخ: 2026-11-06. الخطة: `docs/plans/beta-readiness.md`. طلب السحب: #7.

## ما صار

- **Docker:** `docker compose up -d` على Windows وmacOS وLinux. الصورة فيها Node 24، وأدوات القراءة (Poppler، وMuPDF، وTesseract بالعربي والإنجليزي)، وClaude Code وCodex لتسجيل الدخول بالاشتراك. كل البيانات في مخزن `qbank-data` (قاعدة البيانات، والملفات، والنسخ الاحتياطية، وتسجيلات الدخول)، وتبقى مع التحديث. البرنامج يعمل بمستخدم عادي لا root، ومنشور على `127.0.0.1` فقط.
- **المتصفح على نفس الجهاز يرتبط بلا رمز من داخل Docker:** `QBANK_LOCAL_PEERS` يعدّ شبكة Docker «هذا الجهاز»، مع بقاء الشرطين الآخرين (اسم المضيف `localhost`، ولا وكيل بينهما). وإن لم يتعرّف عليه إعداد ما، يطبع البرنامج رابط ربط في سجله.
- **فحص الدخان** (`scripts/smoke.mjs`): يربط كما يفعل المالك، وينشئ بنكاً، ويستورد ملف PDF مرفقاً من 8 أسئلة، ويتأكد أنها قُرئت كلها. و`--after-upgrade` يتأكد أن بنك النسخة السابقة باقٍ بأسئلته.
- **سير عمل «التثبيت النظيف»** في GitHub:
  - **Docker:** بناء الصورة من الصفر، وتشغيل النسخة السابقة (`main`) وإنشاء بيانات، ثم النسخة الجديدة على البيانات نفسها، ثم إعادة تشغيل.
  - **Ubuntu نظيف:** `install.sh` من الصفر ثم فحص الدخان.
  - **macOS نظيف:** `install.sh` من الصفر (Homebrew يجلب Node والأدوات) ثم فحص الدخان. يعمل أسبوعياً، وعند الطلب، وعلى طلبات السحب بالعلامة `macos` (دقائقه أغلى بعشرة أضعاف).

| المشكلة                                                                        | من سيقع فيها                | الإصلاح                                                                            |
| ------------------------------------------------------------------------------ | --------------------------- | ---------------------------------------------------------------------------------- |
| Homebrew يثبّت Node 26، ولم يعد معه `corepack`، فيتوقف التثبيت عند حزمة الذكاء | **كل مستخدم Mac جديد**      | `pnpm` 10 عبر `npx` حين يغيب `corepack`                                            |
| `apt-get install` دون تحديث القوائم أولاً يفشل على جهاز قوائمه قديمة           | مستخدمو Linux على جهاز جديد | تحديث القوائم قبل تثبيت أدوات القراءة                                              |
| رسالة فشل التثبيت تقول «npm ci failed» فقط، بالإنجليزي                         | كل من يتعثر تثبيته          | لكل خطوة سبب وما يفعله بالعربي، ثم بديل Docker وطريقة التبليغ (جُرّبت بمحاكاة فشل) |
| في Docker يأتي المتصفح من عنوان شبكة Docker لا من `127.0.0.1`، فيُطلب منه رمز  | كل مستخدم Docker            | `QBANK_LOCAL_PEERS` (أعلاه)                                                        |

## باقٍ من M25

- **M25.3 ترقية من إصدار سابق فعلي:** الوظيفة جاهزة، لكن `main` لم يكن فيه Docker بعد، فلم تُجرَّب ترقية Docker من نسخة سابقة. تبدأ تلقائياً من الدمج القادم.
- **M25.5 Windows يدوياً:** لا يوجد في GitHub جهاز Windows بـDocker Desktop. يحتاج تجربة على جهاز حقيقي (منك أو من مختبر)، وهي أول ما يُطلب في التجربة المحدودة.
- **ملاحظة:** npm الذي مع Node 26 لم يعد يشغّل سكربتات التثبيت تلقائياً. التثبيت نجح رغم ذلك، لكنه يستحق مراقبة.
